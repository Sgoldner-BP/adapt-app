# ADAPT Resilience app

The A.D.A.P.T. Method for Movement Resilience, by Aaron Martin and Dr. Sam Goldner, DPT, CSCS, Pn1.

A small offline-capable web app (PWA): Pre-ADAPT Screening, the five steps, daily and weekly tracking, check-ins, and a coach view. Everything a person enters stays on their own device; nothing is stored on a server.

Served by GitHub Pages at app.adaptbeyondlimits.com. Bump `VERSION` in `sw.js` with every release so installed copies update.
